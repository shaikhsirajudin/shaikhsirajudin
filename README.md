- **Full stack:** C#, .NET Core / .NET 8, Python, Go, and Node.js on the backend; Angular (2–18) and React on the frontend.
- **Cloud-native:** event-driven microservices and serverless architectures on **AWS, Azure, and GCP**, with Kafka, RabbitMQ, and SQS for messaging.
- **Healthcare depth:** EMR, payer systems, claims processing, HL7, X12, NCPDP, **FHIR and SMART on FHIR**, and TriZetto Facets.
